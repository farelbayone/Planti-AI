# Planti AI: Digital Plant Expert

Planti AI is a plant-care web app built with Streamlit. It combines an AI chatbot with practical tools for plant owners: disease detection from photos, care schedules with reminders, plant recommendations, and a growth journal. The AI runs on Google Gemini and starts automatically once the app is deployed.

> **Disclaimer:** Planti AI gives general plant-care guidance generated by an AI model. For valuable plants or severe infestations, consult a local nursery or agronomist.

## Features

| Feature | What it does |
|---|---|
| **AI consultation** | Chat about watering, light, soil, fertilizer and pests. Images can be attached to a message. |
| **Disease detection** | Upload a plant photo. Gemini Vision returns a structured result: plant name, health status, disease name, confidence and care steps. |
| **Care schedule and reminders** | Set watering, fertilizing and pruning intervals. The next due date is recalculated automatically each time a task is marked done, and overdue tasks show as a badge in the sidebar. |
| **Plant recommendations** | Enter your location type, light level and humidity to get a list of suitable plants. |
| **Growth journal** | Log notes, photos and plant height by date for each plant in your collection. |
| **My plants** | Keep a personal collection with species, location, light and humidity details. |
| **Accounts** | Register and log in. Passwords are hashed with PBKDF2-SHA256 and a per-user salt, never stored as plain text. |

## Tech Stack

- **Framework:** Streamlit (Python 3.10+)
- **AI:** Google Gemini API (text and vision)
- **Database:** SQLite (`planti_app.db`)
- **Config:** `.env` locally, Streamlit Secrets or environment variables when hosted

## Getting Started

### 1. Get an API key
Create a key in [Google AI Studio](https://aistudio.google.com/apikey).

### 2. Run locally (Windows)
1. Install Python 3.10 or newer.
2. Double-click `Jalankan_Planti.bat`. On the first run it creates a virtual environment, installs the dependencies, creates `.env` from the template and opens it so you can paste your `GEMINI_API_KEY`.
3. The app opens in your browser at `http://localhost:8501`.

Run the same file again whenever you want to use the app. To start it automatically with Windows, run `Aktifkan_Auto_Start.bat` once. To undo it, run `Matikan_Auto_Start.bat`.

### 3. Run manually (any OS)
```bash
python -m venv venv
# Windows: venv\Scripts\activate   |   macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # then add your GEMINI_API_KEY
streamlit run app.py
```

### Configuration

| Variable | Purpose |
|---|---|
| `GEMINI_API_KEY` | Your Gemini API key (required) |
| `GEMINI_TEXT_MODEL` | Model used for chat (optional) |
| `GEMINI_VISION_MODEL` | Model used for photo analysis (optional) |

Model names change over time. Check Google's current model list and pricing before deploying, and choose a model that supports image input for the vision setting.

## Deployment

The simplest option is **Streamlit Community Cloud**:

1. Push the repository to GitHub.
2. In [share.streamlit.io](https://share.streamlit.io), create a new app from the repository with `app.py` as the entry point.
3. Open **Settings → Secrets** and add:
   ```toml
   GEMINI_API_KEY = "your-api-key"
   ```
4. Save. The app restarts and the AI is active for everyone who opens the link.

Hugging Face Spaces (Streamlit SDK), Render and Railway also work. Set `GEMINI_API_KEY` in each platform's environment variables or secrets.

The free Gemini tier has request limits. If the app gets regular traffic, you may see quota errors, and enabling billing on the linked Google Cloud project raises the limits.

## Database

SQLite with six tables. One **user** has many **plants**, and each plant can have many **plant_journal** entries and **care_schedule** entries.

| Table | Stores |
|---|---|
| `users` | Username, salted password hash, name, email |
| `chat_sessions` | Chat title, messages (JSON), pinned flag |
| `plants` | Name, species, location, light, humidity, photo, notes |
| `plant_journal` | Dated notes, photos and height per plant |
| `care_schedule` | Care type, frequency, last done and next due dates, reminder flag |
| `diagnosis_history` | Photo, health status, disease, confidence and the full AI result (JSON) |

## Security

- Passwords use PBKDF2-SHA256 with a per-user salt (200,000 iterations).
- API keys are read from `.env` or the hosting platform's secrets. They are never written in source code.
- `.env`, `venv/` and `planti_app.db` are listed in `.gitignore`. **Never commit them.**
- If a key is ever exposed, revoke it in Google AI Studio and create a new one.
